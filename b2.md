| # | Vị trí                                   | Loại vấn đề               | Mô tả                                                      | Hậu quả                             | Cách khắc phục                                                                     |
| - | ---------------------------------------- | ------------------------- | ---------------------------------------------------------- | ----------------------------------- | ---------------------------------------------------------------------------------- |
| 1 | `<%! private int requestCounter = 0; %>` | Race Condition            | Biến khai báo ở mức instance, dùng chung cho nhiều request | Sai lệch dữ liệu, không thread-safe | Không dùng biến instance trong JSP, chuyển sang Controller hoặc dùng request scope |
| 2 | `<% for(...) { %>`                       | Logic trong View          | Viết vòng lặp Java trực tiếp trong JSP                     | Vi phạm MVC, khó bảo trì            | Dùng JSTL `<c:forEach>`                                                            |
| 3 | `<%= student.getName() %>`               | Expression (cũ)           | Không escape dữ liệu đầu ra                                | Dễ bị XSS                           | Dùng `<c:out value="${student.name}" />`                                           |
| 4 | `<!-- comment -->`                       | HTML Comment sai          | Comment vẫn hiển thị phía client                           | Lộ code, lộ logic                   | Dùng JSP comment `<%-- --%>`                                                       |
| 5 | `<%= ...; %>`                            | Sai cú pháp               | Expression không cần dấu `;`                               | Có thể lỗi runtime                  | Bỏ dấu `;`                                                                         |
| 6 | Java `if/else` trong JSP                 | Business Logic trong View | Đặt logic xử lý trong JSP                                  | Code rối, khó test                  | Đưa logic sang Controller hoặc dùng `<c:if>`                                       |
| 7 | In dữ liệu user trực tiếp                | XSS                       | Không kiểm tra/escape input người dùng                     | Bị inject script                    | Escape dữ liệu, validate input, dùng `                                             |

Phần 2: 
    report.jsp
        <%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>
        <%-- Trang báo cáo sinh viên --%>
        <html>
        <head>
            <title>Student Report</title>
        </head>
        <body>

        <h2>Danh sách sinh viên</h2>

        <table border="1">
            <tr>
                <th>Tên</th>
                <th>Điểm</th>
                <th>Xếp loại</th>
            </tr>

            <c:forEach var="student" items="${students}">
                <tr>
                    <td>
                        <c:out value="${student.name}" />
                    </td>
                    <td>
                        <c:out value="${student.score}" />
                    </td>
                    <td>
                        <c:choose>
                            <c:when test="${student.score >= 8}">
                                Giỏi
                            </c:when>
                            <c:when test="${student.score >= 5}">
                                Khá
                            </c:when>
                            <c:otherwise>
                                Yếu
                            </c:otherwise>
                        </c:choose>
                    </td>
                </tr>
            </c:forEach>

        </table>

        </body>
        </html>
